# Foldage

木構造そのものをプログラムとして扱い、実行＝木の書き換え（tree / term rewriting）によって計算が進行する難解プログラミング言語。木は葉から根へ「畳まれて」いき、根が単一のアトムになったら、それが出力になる。

ドキュメント（図解・言語仕様・サンプルの解説）: https://snowman-s.github.io/Foldage/

## 特徴

- **ルールも木の一部**: 書き換えルール自体が木の中のノードで、計算の途中でルールが書き換わりうる（メタ書き換え）。ルールを生成するルールも書ける
- **自己改変が終了の条件**: プログラムは最後に自分のルールを畳み込んで消さなければ終われない

構文・変数・組込みの要点は[言語仕様の 1.3 節](docs/spec.md)にまとめている。

## 例

```
main
  -> (add z ?n) ?n
  -> (add (s ?m) ?n) (s: add ?m ?n)
  -> (show z) ""
  -> (show: s ?n) (++ "|": show ?n)
  -> (main ?..rules ?r) ?r    # ルール群（自分自身を含む）ごと main を畳む
  show: add (s: s z) (s z)
```

2 + 1 をペアノ数で計算し、`|||` を出力する。

## 処理系

Rust で実装している（クレート名 `foldage`、外部依存なし）。

```
cargo run -- samples/ex1-add.fdg                 # ||| を出力
cargo run -- samples/ex2-meta.fdg --trace        # 各ステップの木を正規形で標準エラーに表示
cargo run -- <file> --max-steps 1000             # ステップ数の上限を付けて実行
cargo run -- <file> --burn                       # 止まった時点の木でソースファイルを上書きする
cargo test                                       # 全テスト
```

- 出力は根に残ったアトムそのもので、末尾に改行は付かない
- `--burn` は、正常終了・折りたたみ失敗・ステップ数の上限のどれで止まっても、その時点の木を正規形でソースファイルに書き戻す。畳み切ったプログラムは出力のアトム 1 つ（例: `"|||"`）になり、上限で止まったプログラムは続きから再実行できる。読み込み・構文のエラーでは書き戻さない。書き戻しは `<ファイル>.burn` に書き切ってから置き換えるので、失敗しても元のソースは残る
- 終了コード: 0 正常終了 / 1 折りたたみ失敗・ステップ数の上限 / 2 使い方・読み込み・構文・書き戻しのエラー
- サンプルは `samples/` にある。`cargo test` で、ドキュメントに書いたステップ数と出力になることを確かめる
