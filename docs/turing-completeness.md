# チューリング完全性

任意の 2-タグシステムを Foldage のプログラムに翻訳でき、その実行がタグシステムの動作を 1 ステップずつなぞることを示す。2-タグシステムはチューリング完全なので、Foldage もチューリング完全になる。意味論は[言語仕様](spec.md)第 5 章・第 6 章に従う。

## 1. 2-タグシステム

2-タグシステムは、有限のアルファベット Σ と、各記号 x ∈ Σ に対する生成規則 P(x) ∈ Σ* の組である。語 u に対して、次の 1 ステップを繰り返す。

- u の長さが 2 未満なら停止する
- そうでなければ、u の先頭の記号を x として、u の先頭から 2 記号を消し、末尾に P(x) を足す

Cocke と Minsky は、任意のチューリング機械を 2-タグシステムで模倣できることを示した（J. Cocke, M. Minsky, "Universality of Tag Systems with P = 2", J. ACM 11(1), 1964）。したがって、任意の 2-タグシステムを模倣できる体系はチューリング完全である。

## 2. 翻訳規則 T

タグシステム (Σ, P) と初期語 w = w₁ w₂ … wₙ を、次の Foldage プログラム T(Σ, P, w) に翻訳する。語は `tag` ノードの子の列として表す。

```
main
  # 各 x ∈ Σ について 1 本（ステップ規則 Rₓ）。P(x) = p₁ … pₖ
  ->
    tag x ?y ?..w
    tag ?..w p₁ … pₖ
  # 停止処理
  -> tag ""
  ->
    tag ?x
    show ?x
  # 各 x ∈ Σ について 1 本（表示規則 Sₓ）
  ->
    show x
    "x"
  # 終了規則 F
  ->
    main ?..rules ?r
    ?r
  tag w₁ w₂ … wₙ
```

- P(x) が空なら、Rₓ の置換は `tag ?..w` になる
- w が空なら、最後の子は子のない `tag`（シンボル `tag` の葉）になる
- 簡単のため、Σ の記号名は Foldage のシンボルとして書けて、`tag`・`show`・`main`・`->`・`++` のいずれとも異なるものとする
- また、記号名は `\` を含まないものとする。Sₓ の `"x"` は文字列リテラルなので、`\` がエスケープとして読まれ、記号名と違う文字列になってしまうため

## 3. 模倣の補題

**補題.** 木が T の形で、最後の子が `tag u` であるとする（u は語）。このとき、次のステップで書き換わるのは `tag u` で、その結果は次のとおりになる。

| u の状態 | 当たるルール | 結果 |
|---|---|---|
| 長さ 2 以上、先頭が x | Rₓ | `tag u'`（u' はタグシステムの 1 ステップ後の語） |
| 長さ 1（u = x） | `tag ?x` | `show x` |
| 長さ 0 | `-> tag ""` | `""` |

**証明.** 帰りがけ順で `tag u` より先に調べる位置は、`main` の子のルールのノードと、`tag u` の子である記号の葉だけである。これらにはどのルールも当たらない。

- ルールのノード: ラベルは `->` である。どのパターンもラベルが `tag`・`show`・`main` のいずれかなので当たらない。組込みの連結もラベル `++` にしか当たらない
- 記号の葉: 子のないノードに当たりうるパターンは `-> tag ""` の `tag` だけである。しかし記号名は `tag` と異なると仮定した

次に `tag u` の位置では、パターンが `tag` で始まるのは Rₓ、`tag`、`tag ?x` で、子の数でちょうど 1 本に絞られる。

- 長さ 2 以上: `tag`（子 0 個）と `tag ?x`（子 1 個）は当たらない。Rₓ は 1 つ目の子がリテラル x なので、先頭の記号と同じ x の 1 本だけが当たる。このとき `?y` が 2 つ目の記号に、`?..w` が残りに束縛される。置換 `tag ?..w P(x)` はタグシステムの 1 ステップそのものである
- 長さ 1、長さ 0: Rₓ は子が 2 個以上必要なので当たらない。それぞれ `tag ?x`、`tag` だけが当たる

置換にラベル位置の変数はないので、置換の組み立ては必ず成功する。□

`show x` と `""` が現れたあとは、次のように進んで終わる。

- `show x` は、子 x の葉には何も当たらず、Sₓ で文字列 `"x"` になる
- 最後に `main` の位置で F が当たり、根が文字列になって停止する。文字列の葉にはどのパターンも当たらないので、F より先に当たる位置はない

## 4. 結論

補題を初期語から繰り返し使うと、次が成り立つ。

- タグシステムが k ステップで語 v（長さ 2 未満）に至って停止する ⇔ T(Σ, P, w) が畳み切り、v を連結した文字列を出力する
  - Foldage のステップ数は、k + (v が空なら 1、そうでなければ 2) + 1 になる
- タグシステムが停止しない ⇔ T(Σ, P, w) は書き換えを永遠に続ける（根の `main` は一度も調べられない）

T は (Σ, P, w) から機械的に作れるので、任意のチューリング機械は「Cocke–Minsky の構成で 2-タグシステムにする → T で Foldage にする」という手順で Foldage に翻訳できる。よって **Foldage はチューリング完全である**。

### 補足

- 無制限の記憶は、`tag` ノードの子の数に上限がないことで得ている。列変数 `?..w` が任意の長さの列を 1 回で束縛し、置換で展開するので、テープ全体を 1 ステップで回せる
- この構成は、メタ書き換えも組込みの `++` も使わない。チューリング完全性だけなら、言語のごく小さな部分で足りる
- ただし自己改変は避けられない。プログラムを終わらせるには、最後に F が自分を含むルール群を畳んで消す必要がある（[言語仕様](spec.md) §6.6）
- 停止記号 H で止まる変種のタグシステムも、`tag H ?..w` を `show H` に書き換えるルールを Rₓ の代わりに置けば、同じように翻訳できる

## 5. 例: Collatz タグシステム

De Mol の 2-タグシステム（L. De Mol, "Tag systems and Collatz-like functions", Theoretical Computer Science 390(1), 2008）は、Σ = {a, b, c}、P(a) = bc、P(b) = a、P(c) = aaa である。語 aⁿ（n ≥ 2）から始めると、数ステップ後に、n が偶数なら a^(n/2)、奇数なら a^((3n+1)/2) になる。つまり Collatz の列を追い、a¹ に至って止まる。

これに T を適用したものが [samples/ex5-tag.fdg](https://github.com/Snowman-s/foldage/blob/main/samples/ex5-tag.fdg)（初期語 a⁷）である。出力は `a` で、タグの 128 ステップを含む 131 ステップで止まる。

### 初期語 a³ の場合

`tag` ノードの子の列だけを示す。各行が Foldage の 1 ステップに対応する。

| step | 語 | Collatz |
|---|---|---|
| 0 | `a a a` | 3 |
| 1 | `a b c` | |
| 2 | `c b c` | |
| 3 | `c a a a` | |
| 4 | `a a a a a` | 5 |
| 5 | `a a a b c` | |
| 6 | `a b c b c` | |
| 7 | `c b c b c` | |
| 8 | `c b c a a a` | |
| 9 | `c a a a a a a` | |
| 10 | `a a a a a a a a` | 8 |
| 11 | `a a a a a a b c` | |
| 12 | `a a a a b c b c` | |
| 13 | `a a b c b c b c` | |
| 14 | `b c b c b c b c` | |
| 15 | `b c b c b c a` | |
| 16 | `b c b c a a` | |
| 17 | `b c a a a` | |
| 18 | `a a a a` | 4 |
| 19 | `a a b c` | |
| 20 | `b c b c` | |
| 21 | `b c a` | |
| 22 | `a a` | 2 |
| 23 | `b c` | |
| 24 | `a` | 1 |

このあと、step 25 で `tag a` が `show a` に、step 26 で `"a"` になり、step 27 で `main` が畳まれて `a` を出力する。27 = 24 + 2 + 1 で、第 4 節の式と合う。

## 6. 検証

[tests/tag_system.rs](https://github.com/Snowman-s/foldage/blob/main/tests/tag_system.rs) で、T が補題どおりに働くことを確かめている。

- タグシステムを Rust で直接動かした結果と、T で翻訳した Foldage の出力・ステップ数が一致する（Collatz 系の n = 1〜12、空の生成規則を持ち空の語で止まる系）
- 停止しない系は、Foldage でもステップ数の上限まで止まらない
- samples/ex5-tag.fdg が、Collatz 系と a⁷ に T を適用したものと同じ木になる
